# 🌸 BloomWorld

BloomWorld - Responsive flower & garden e-commerce homepage built with HTML5, CSS3 Flexbox & Grid.

Mobile-first UI with category shop, product grid & promo banners.

## 🚀 Features
- Fully responsive layout (Mobile / Tablet / Desktop)
- Flexbox & CSS Grid product showcase
- Category shop section with hover effects
- Promo banners & newsletter section
- Clean, modern UI with custom fonts

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts

## 📱 Responsive
- Mobile: 320px - 767px
- Tablet: 768px - 1023px  
- Desktop: 1024px+
